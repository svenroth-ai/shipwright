Claude-side worktree gate for `/shipwright-iterate`: `iterate_worktree_gate.py` arms on the slash command or a `Skill` call and, until the run is in a linked worktree, denies edits to the main checkout and non-read-only shell commands with the exact `setup_iterate_worktree.py` command to run. Re-judges live state on every call (cwd in a worktree or a genuine run pointer), fail-open, no-op under Codex; `SHIPWRIGHT_ITERATE_WORKTREE_GATE=off` disables it for the environment, or the user typing exactly `iterate gate off` releases one session. `--campaign` runs are never armed. The Codex PreToolUse matcher now also rejects composite shell punctuation (`&>`, `>&`, `>|`, `|&`) and keeps a mid-word `#` from hiding the rest of a command.
