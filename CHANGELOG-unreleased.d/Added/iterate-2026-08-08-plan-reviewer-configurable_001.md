shipwright-plan / shipwright-iterate: the internal plan-review's model is now configurable via `shipwright_model_config.json`'s new `plan_review` role (`--plan-review-model` on `/shipwright-iterate`; project-config only for `/shipwright-plan`, which has no invocation flags), instead of being hard-wired to `opus` in `opus-plan-reviewer.md`'s frontmatter. Unset resolves to the session model (`inherit`), matching the other three roles — set `plan_review` explicitly to keep opus. `/shipwright-iterate`'s own mini-plan review gains the same internal-reviewer arm Step 5-int already had (medium+ complexity). A stale plugin-cache install may log `unrecognized key(s) ['plan_review']` for a project config carrying the new key — benign, resolved by `bash scripts/update-marketplace.sh`. The review record's `REVIEW_TYPES` vocabulary also gains `plan_internal` (the internal arm's own row, distinct from `plan`'s external one); a session with a `reviews.json` already `init`ed before this update merges into its worktree mid-run may see F11 STOP on `plan_internal still unanswered` — recover with `record_review_pass.py close-missing`, same as any run whose review record predates a newly-added type.
