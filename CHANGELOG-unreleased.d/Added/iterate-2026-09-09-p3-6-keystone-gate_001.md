**Keystone AC gate** — a new `pull_request`-only CI step (`shared/scripts/tools/check_keystone_ac_gate.py`) blocks a PR that edits an acceptance criterion whose bound test did not run green in that same CI run, or whose test binding the PR silently removes. It reads the traceability manifest the preceding drift step regenerates in place, so a hand-edited committed manifest cannot forge a pass. It enforces spec-to-test consistency: a PR that changes behaviour in code and changes no acceptance criterion passes untouched.
