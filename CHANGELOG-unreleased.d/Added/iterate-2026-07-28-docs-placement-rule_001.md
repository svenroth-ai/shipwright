The user guide now answers which decisions a driven pipeline run makes without asking you. Chapter 4 lists the three settings every interactive checkpoint carries — answer it and continue, stop and ask a human, or always stop with no exception — names which kinds of question fall under each, and states the two guarantees that hold at any autonomy level: a constitution-locked checkpoint such as a secret or a production deploy is never answered automatically, and the whole mechanism is inert outside a driven run. Previously this was documented only in a generated table that nothing linked to.
