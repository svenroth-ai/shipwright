Compliance evidence now discloses when the consistency cross-check last ran. Every document — dashboard, traceability matrix, test evidence, change history, SBOM — states the date and how long before its own generation the check happened, or says plainly that it never has. The audit is on demand by design (no schedule, no CI trigger), so this turns possibly-never-checked into visibly-not-checked-since. A partial (`--only`) run is reported alongside the last whole-project check, never in place of it, and a damaged record reads as `unknown` rather than falsely as `never run`.
