**The plugin-cache drift check now gates all three cache trees.** `scripts/check_plugin_cache_sync.py` used to compare only the versioned plugin dirs and `shared/`; the cross-plugin mirror `cache/plugins/<name>/` stayed deliberately ungated because the SessionStart self-heal hook judged it from a single sentinel file, and a gate on top would have inherited that weakness. Since the healer now validates each mirror against its own repair source, the mirror joins the check via new `scripts/cache_mirror_compare.py` — with its own basis (the literal string `"cache"`, never `git`/`walk`) and state vocabulary (`ok`/`drift`/`not_mirrored`/`no_source`), since its repair source is the plugin's newest cached version, never `installed_plugins.json` (the healer doesn't consult that manifest either — a stray higher version dir is exactly what it mirrors from). `verified` now names all three trees; `ungated` is always empty. The healer still answers a different question (ABSENCE, via file sets) than this check does (STALENESS, via CRLF-normalized content hashes).
