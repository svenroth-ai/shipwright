Finalizing a medium or large change now requires that a code review actually happened, not merely that every review type was answered. Previously all five types could be recorded as `not_run` — each with a written reason — and the run still passed. Recording a review as not applicable does not satisfy the requirement either, since that would make it passable by relabelling. Measured against every existing run before shipping: all 25 larger changes on record already meet it, so nothing in flight is affected. Closing all review types at once still writes a complete record, but for a larger change it no longer makes the run green; for small changes it is unchanged.
