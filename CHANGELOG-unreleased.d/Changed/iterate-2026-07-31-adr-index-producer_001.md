Each ADR index row is now labelled from that ADR file's own `#` heading instead of its filename slug, so the index keeps human wording (e.g. "TT6") that the slug could not express. To change a label, retitle the ADR — the index is generated. Regenerate by hand with `uv run {shared_root}/scripts/tools/rebuild_adr_index.py --project-root .`; a drift guard now fails loudly when the committed index is stale.
