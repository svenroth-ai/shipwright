The pre-commit test gate now records what it finds instead of only printing it: a test unit that fails while the units run side by side but passes when run on its own is written into the project's Triage Inbox by the gate itself, so the observation survives the session that made it. The entry says the cause is undetermined - a clash between simultaneous runs and an unreliable test look identical from there - carries the exact commands to reproduce both sides, and is never closed automatically by a later run that happens to look clean. The gate still does not stop for the unit itself; it now stops only if it cannot write the entry down at all.
