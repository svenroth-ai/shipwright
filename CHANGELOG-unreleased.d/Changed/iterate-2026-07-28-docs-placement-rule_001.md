The repository now states where a document belongs, in CLAUDE.md: `docs/` holds hand-written instructions — for users and developers alike — while `.shipwright/` holds the artifacts Shipwright keeps from its own runs. A file that is neither is not filed somewhere else: a record of finished work is deleted and left to git history, and a generated file that stays in the tree lives next to the source it is generated from. The single-session gate catalog's generated table moved accordingly, from `docs/gate-catalog.md` to `shared/config/gate_catalog.md` beside the JSON it renders; its drift guard moved with it and gained a test pinning the location, so a quiet move back would no longer pass.
