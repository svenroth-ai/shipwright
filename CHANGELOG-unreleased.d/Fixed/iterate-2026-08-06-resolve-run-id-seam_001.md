The Stop-time phase-quality and compliance audits are now keyed by the iterate's own run id instead of the raw session UUID. `resolve_run_id` gained a highest-priority source — the per-session run pointer `setup_iterate_worktree.py` already writes at B1a — so findings, per-run snapshots and mirrored triage cards are attributable to the run that produced them, and the SKIP evidence emitted by the five guarded spec checks (S2, S3, W2, S9, S10) names a real run. A pointer is honoured only when its payload names the audited session and its worktree is still live; a malformed, non-object, invalid-UTF-8 or orphaned pointer falls through to the previous resolution chain rather than raising.
