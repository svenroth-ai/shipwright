Triage delivery can no longer be stopped permanently by a single un-deliverable line. The outbox sweep previously had one failure mode — block everything — for three unrelated situations: a concatenated log line (which the reader recovers, so the board looked fine while nothing shipped), a dismiss whose item lives only on local main, and a status event with no usable id. Each of these stranded the entire pending backlog in a gitignored buffer. Every case now gets a proportional outcome: a line that is not deliverable *yet* is held and retried on the next sweep, one that can never be delivered is quarantined for review, and the rest of the backlog ships either way.
