Finalizing a change now checks evidence that belongs to the run being finalized. The file holding a run's test-completeness ledger, its end-to-end result and its declared removals is rebuilt from the main branch during finalization, so three checks were reading the PREVIOUS run's numbers and reporting them as this one's — one of them could let another run's stated exception excuse a removal nobody declared here. Each check now refuses evidence that does not name this run, and says which run it found instead and how to repair it.
