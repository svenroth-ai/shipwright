**A finalization warning stopped contradicting itself.** The check that a run's hand-over note describes the run now finishing compared the two names literally while displaying them cleaned up, so any difference the cleanup removed — a stray space, an invisible character — produced a warning that named the *same* run on both sides of its own "not". It now compares exactly what it shows, through a normalizer that deliberately does not shorten long names (shortening would have turned a false warning into a false pass).
