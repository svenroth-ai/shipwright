The derived-snapshot gate's printed remedy no longer sends the operator in a circle. On a merge HEAD — the shape the gate was taught to catch — `--source=HEAD~1` named the branch's own pre-merge tip, i.e. the commit carrying the offending snapshot, so following the instruction changed nothing and the next run failed identically. The restore source is now the branch's merge-base with the default branch, and when no base resolves the gate prints no command at all rather than a wrong one.
