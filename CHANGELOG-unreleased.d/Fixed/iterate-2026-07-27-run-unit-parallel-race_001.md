Windows: a concurrent reader no longer costs a writer its write, and a concurrent writer no longer costs a reader its read. `os.replace` is atomic on Windows only when it succeeds, so every `shipwright_*` config/state/log write (30 call sites) could fail outright whenever any process — the WebUI, an editor, an indexer, antivirus — held the file open. Both directions now retry a sharing violation for a bounded budget and still fail loudly past it.
