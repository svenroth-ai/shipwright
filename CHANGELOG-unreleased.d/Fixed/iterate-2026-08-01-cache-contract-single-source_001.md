`check_plugin_cache_sync.py` now resolves each plugin's cache directory from `installed_plugins.json` — the same file `update-marketplace.sh` writes into — instead of picking the highest SemVer directory present. A stale surviving version dir could otherwise make the sync report "up to date" while `--strict` reported drift with every repo file missing. Where the manifest cannot be read the highest version is still used, but the run now says so (`version_basis`) on both the ok and the drift line.
