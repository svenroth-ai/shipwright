The external code review is no longer chained behind the internal one. It used to fire only if the internal reviewer had fired, which put both behind a single point of failure: if the internal pass could not run for any reason, the external pass was excused along with it and a larger change could finish with no code review at all. It now fires on its own conditions, and when the internal reviewer cannot run the responsibility moves outward instead of lapsing — the external review becomes mandatory and carries the pass. Decoupling also exposed a contradiction the chain had been hiding: a small change touching security-sensitive files both did and did not require the cascade. The exemption for small changes now applies only when none of the thresholds is met.
