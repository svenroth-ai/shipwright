The F1 artifact-drift check no longer reports a git failure as a clean tree: `artifact_sync` routes through `run_git` (utf-8, bounded, kill+reap), checks the return code, and emits an explicit `error` that `finalize_bundle` maps to `failed`. A repo with too little history to compare stays a non-blocking no-op, so a greenfield first iterate can still finalize; an unknown or malformed ref stays loud.
