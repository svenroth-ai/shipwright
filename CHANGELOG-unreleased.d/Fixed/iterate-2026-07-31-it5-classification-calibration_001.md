`touches_build` now detects Python build inputs (`uv.lock`, `poetry.lock`, `Pipfile`, `Pipfile.lock`, `pyproject.toml`, `setup.py`, `setup.cfg`, `requirements*.txt`) on BOTH surfaces — the diff-driven path patterns and the message-keyword patterns that are what actually fire at Step E. Previously the list was JS-only, so a dependency change in a Python repo raised no risk flag. Matching is whole-filename and case-sensitive on every platform (`fnmatchcase`), and git's `core.quotePath` wrapping is stripped before the basename.
