The phase-gate mode reader no longer crashes the gate-policy CLI on a damaged `shipwright_run_config.json`. A config whose top-level JSON is not an object, one that is not valid UTF-8, and one nested past Python's recursion limit each now read as inert (gates stay interactive) instead of ending the process with a traceback. A config carrying a UTF-8 byte-order mark is also read correctly now, so the gate mechanism and the orchestrator agree about whether a run is being driven.
