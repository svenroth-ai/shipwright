# Folding bullet drops (release Step 4 / Step 6)

**Bullet drops fold first.** The same run first folds pending `decision-drops/bullets/*.md` (the architecture / convention / learning bullets iterates wrote with `write_doc_bullet.py`) into the curated sections of `architecture.md` / `conventions.md`, then deletes those files (`bullets_folded` in the summary). Bullets go BEFORE the ADRs so the ADR fallback bullet is not duplicated. Step 6 must stage both docs and the deleted bullet files along with the `decision-drops/` directory (Step 6 builds `BULLET_DOCS` from the ones the project has, so a missing `architecture.md` / `conventions.md` is simply left out of `git add` and the commit pathspec). A bullet whose anchor is already in the doc with different text is KEPT and reported (`fold_bullets.py` warns); resolve it by hand.
