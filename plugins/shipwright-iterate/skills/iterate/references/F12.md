# F12 — Release Prompt

After opening the PR, count the pending changelog drop files — `*.md`
under `{project_root}/CHANGELOG-unreleased.d/` (excluding `.gitkeep`).
If > 0:

> "{N} unreleased changelog drop(s) pending. Once this PR merges, run
> /shipwright-changelog — it aggregates the changelog drops + the ADR
> decision-drops and tags the release."

`/shipwright-changelog` runs against the default branch AFTER the PR
merges, not now — the drops are not on `origin/<default>` yet.

Print summary:

```
================================================================================
SHIPWRIGHT-ITERATE COMPLETE
================================================================================
Run ID:     {run_id}
Type:       {FEATURE | CHANGE | BUG}
Complexity: {level}
Worktree:   .worktrees/{slug}/
Branch:     iterate/{slug}
Commit:     {hash}
Tests:      {N} passing (unit: {N}, e2e: {N|skipped}, design_fidelity: {N|skipped})
Specs:      {iterate spec path | FR update only | no changes}
ADR:        decision-drop {run_id} (ADR-NNN assigned at changelog release)
CHANGELOG:  drop file(s) under CHANGELOG-unreleased.d/
Exemptions: {N | N (reason-code: n, ...)}, share {x% from the F11 test-tag line}   # exemption_summary.py - 0 when none, never omitted
Compliance: Updated
Unavailable: {omit when review_unavailable_note.py prints `none`} N (passes) - did NOT run (unavailable); adapter error: <paths>; re-run card <id>
Reviews:    {omit this row when the internal cascade ran}
            internal cascade NOT RUN — {blocker class, per iteration-reviews.md step 0}
PR:         {pr_url} — open for review
================================================================================
```

**The `Reviews:` row is conditional and load-bearing.** Print it only when the
Step-8 cascade did not run, naming which of the four blockers applied. Omit it
entirely when the cascade ran — a row that always appears stops being read. This
is the surface SKILL.md Step 8 promises under `--autonomous`: the operator learns
here that a pass is missing and can lift a gating policy for the next run. Left
off the banner, that promise points at nothing.

**The `Exemptions:` row is unconditional.** Every exemption a gate accepted this run
(a single untagged test a gate let through, ...) is one item in the F5c entry's
`exemptions` block (`references/F5c.md`). A review pass closed `not_run` is NOT an exemption: it
explains itself through its own `reason_code` in `reviews.json`. The count is printed here and in the PR body so a
"0" is a statement and a "7" is visible. Run
`uv run "{shared_root}/scripts/tools/exemption_summary.py" --project-root "{project_root}" --run-id "{run_id}"`
and paste its line, followed by the exemption share F11's `check_test_tag_binding` line prints
(`exempted M of K added/edited tests`). `INVALID - ...` (exit 1) means the record is broken: fix F5c,
do not print "0"; `not recorded (legacy entry)` means the entry predates the block.

**The `Unavailable:` row is conditional, and loud when it appears.** A pass closed
`not_run --reason-code unavailable` is a review that could not run (the external reviewer
errored, every reviewer came back degraded, `uv run` failed). The run may continue, never
silently: paste the line of
`uv run "{shared_root}/scripts/tools/review_unavailable_note.py" --project-root "{project_root}" --run-id "{run_id}"`
here and in the PR body whenever it is not `none` (an autonomous run adds `--file-triage`, which
files one re-run card per run and appends its id). `INVALID - ...` (exit 1) means the record is
broken or the card was not filed: say so, never print `none`. The capture rule behind it:
`campaign-step-3-5-plan-review.md` → *Unavailable*.
