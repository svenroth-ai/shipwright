# Architecture brief: U2 delta backfill
Options: (a) hand-map the 1,440 delta tests to FRs by judgement and write tags; (b) run the existing deterministic engines, write what they prove, record the rest as one triage card with a measurement doc; (c) do nothing.
Chosen: (b). No new mechanism, no permanent code added; the only repo changes are one evidence doc and one triage card.
