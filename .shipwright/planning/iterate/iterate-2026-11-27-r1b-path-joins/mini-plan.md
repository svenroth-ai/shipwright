# Mini-plan: r1b-path-joins

1. **Codemod (AST, byte offsets):** for every production `.py` (not tests, not the resolver), each `BinOp(Div, <left>, _sp.rel(<arg>))` becomes `_sp.path(<arg>, <left>)`; a `Path(<x>)` left side with one positional argument becomes `<x>` (`path()` wraps the root in `Path`). The file is re-parsed after the edit. Survey before the edit: 98 sites in 67 files, left sides 89 plain names (`project_root` 78, `root` 7, `cwd` 3, `child` 1) and 9 `Path(x)` calls; no chained or nested joins; no test replaces `_sp`.
2. **Not touched:** hook fallbacks `root / ("<lit>" if _sp is None else _sp.rel(k))` (7 files; R1a pins their shape; the resolver may be absent there, so `_sp.path` cannot be called) and module-level constants bound to `rel()` (80 names in 72 files; frozen at import, used as basenames, git pathspecs or joined later). Both are R1c's, written into BRIEF 12 item 10.
3. **Guard:** `_shipwright_paths_scan.py` gains `rel-join` (Div / `joinpath` / `os.path.join` whose operand is, or through an `IfExp` yields, `rel()`/`name()`/`legacy_rel()` on `_sp`/`sp`/`shipwright_paths`) and `rel-constant` (module-level `Assign`/`AnnAssign`, also inside module-level `if`/`try`, whose value contains a `rel()` call). `rel-join` uses the file allowlist (`REL_JOIN_ALLOWED`, the 7 fallback files, reasoned); `rel-constant` uses a per-name closed inventory in `shared/tests/fixtures/shipwright_paths_rel_constants.json` (new name fails, vanished name must be removed). Positive controls for each shape; the negative control (old code) flags all 98.
4. **Verify:** resolver + guard + fallback + basename tests, ruff, full F0 suite.
