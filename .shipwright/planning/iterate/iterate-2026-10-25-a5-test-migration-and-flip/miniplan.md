# Mini-plan A5: test migration and flip to enforcing (campaign brief-driven-run-a-real-gates)

Goal: BRIEF D4 step (3), acceptance A5: "all migrated tests green on real minimal artifacts (not weakened); default is enforcing; a deliberately broken artifact stops a driven run end to end."

Problem: A4 shipped the phase gate in `single-session-apply` behind `ENFORCE_PHASE_GATE_DEFAULT = False`. About a dozen tests complete driven phases with stub artifacts (a one-line file named in `artifacts[]`) that no real validator accepts, so flipping the default would red them; the docs say enforcement is OFF.

Changes:
1. Precondition proof (A4 hand-over 1): new `plugins/shipwright-run/tests/test_phase_gate_cache_layouts.py` builds each install layout the plugin ships in (Claude cache `<cache>/shipwright/shipwright-run/<ver>` + `<cache>/shipwright/shared`, the `plugins/shipwright-run` mirror, the Codex bundle `origin/shipwright-run` + `shared`, the checkout) and, in an isolated subprocess, runs the real gate over a minimal valid project: enforced, checked, no ask, no canon_degraded, and `tools.verifiers` resolved from THAT layout's shared tree. Negative control: shared without verifiers -> canon_degraded ask (fail closed). Also probed by hand against the real installed cache.
2. One shared builder `shared/testkit/minimal_valid_project.py` (no `lib`/`scripts`/`tools` package, imported as a bare module after a `sys.path` insert of its own directory, so it is ADR-044-safe from both the run root and `integration-tests`): `write_phase(root, phase, split_id=None, *, splits=...)` writes the smallest artifacts each phase's REAL validator + canon checks accept and returns the list a phase-runner would claim. C1 is satisfied through a `phase_history` terminal outcome, not a `phase_completed` event (the event is dedup-keyed and would swallow the loop's own end event).
3. Migrate every stub-artifact ok:true apply to the builder: run root (`test_single_session_loop`, `_artifact_guard`, `_cli`, `_phase_started`, `_resume`, `test_lifecycle_cli`, `_gate_seam`, `_gate_hardening`) and integration (`test_single_session_pipeline`, `_capstone`, `_resume_integration`, `_sole_mode`, `test_handoff_reads_real_loop_state`, `test_cross_surface_backcompat`, `test_phase_invocation_mode_integration`). No assertion weakened; raw `complete-phase-task ok:true` call sites switch to `single-session-apply` (precondition 3), and `test_lifecycle_cli` now pins the refusal.
4. Flip `ENFORCE_PHASE_GATE_DEFAULT = True`; seam/hardening tests assert the new default and keep an explicit off case.
5. New `integration-tests/test_driven_run_real_gate_e2e.py`: drive the real CLI; a design manifest names a missing screen; every retry via `single-session-next`; guided ends at `ask_human` (task in progress) and passes once fixed; autonomous strict-stops (`failed`), `single-session-recover` + fix passes; both drive on to `complete`.
6. Docs: `docs/hooks-and-pipeline.md`, `docs/guide.md`, run `SKILL.md`, `single-session-loop.md`, deploy `SKILL.md` (stale Stop-hook completion text). Decisions recorded there: `--force-status skipped` on an in-progress task needs no recorded reason (operator-only escape hatch, skipped is not done, no successor; a skipped design is still refused by the design validator downstream); inform notes on the v2 pass path are returned, not persisted (the master relays them).

Alternative approach considered: keep per-file stub fixtures but mark them gate-off with `enforce_gate=False` - rejected because it would make the migrated tests pass by switching the gate off, i.e. weaken them.
Alternative approach considered: put the builder in `shared/scripts/lib` - rejected: importing it from a plugin root would load shared `lib` into a process whose `lib` is the plugin's (ADR-044).

Tests: measured roots `plugins/shipwright-run/tests` and `integration-tests` (the latter `--cov=shared`, so `shared/testkit` is measured).
Risks: real-artifact apply is slower per phase (canon checks run); full drives take seconds, not milliseconds. A third-party layout not in the four proven ones would fail closed (canon_degraded ask), never pass silently.
