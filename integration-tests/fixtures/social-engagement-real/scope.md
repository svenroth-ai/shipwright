# Scope

In: a plugin with one skill that starts and stops a local companion, a served master-detail board (thread list on the left, one thread on the right), fetching hits through an exchangeable source adapter (a recorded Syften and Apify answer stands in for the network), reading a thread with a summary, drafting a reply and copying it, giving feedback on a draft, marking a thread posted or skipped, filtering by platform and status, setting the sources (Syften filters and LinkedIn queries). A Python backend with a JSON API and JSON files in a data folder, a deterministic local reply drafter.

Out: a chat interface in the app (the chat is the Claude app), calling any real service or model in a test, keys, posting anything, a review by other models, accounts and sign-in, deployment, sending notifications.
