# Visual guidelines

Warm and calm: a beige page, white-ish cards, one teal accent, a rust colour only for warnings and expired threads. Inter for text, Geist Mono for small labels, counts and eyebrows. Look and structure come from the Untitled UI design kit; this file supplies the brand tokens, declared as `--name: value` lines so the kit can read them. The thread on the right looks like the platform it came from (author, points, a comment tree), not like a generic card.

- --font-size-base: 16px

- --font-size-lg: 18px

Inter for text and headings, Geist Mono for eyebrows, counts and platform labels (upper case, wide letter spacing).

## Spacing
- 4px base unit; 12px inside list rows, 16px between blocks, 14px card radius, 8px control radius
