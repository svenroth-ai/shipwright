# Visual guidelines

Calm, high contrast, one accent colour. A chat column and a pane, nothing else.

## Colours
- Background #f6f7f9, surface #ffffff, text #111827, muted #6b7280, border #d0d5dd
- Accent #2563eb (on-accent #ffffff); status new #b45309, drafted #1d4ed8, posted #15803d

## Typography
- System sans-serif, 16px body, 20px headings, 13px for badges

## Spacing
- 4px base unit; 12px inside bubbles and cards, 16px between blocks
