# Scope

In: a plugin with one skill that starts and stops a local companion, a served board with a tab per platform, fetching seeded matches, showing a thread, drafting a reply, marking a thread as posted, setting keywords. A Python backend with a JSON API and JSON files in a data folder, a deterministic local reply drafter.

Out: a chat interface in the app (the chat is the Claude app), calling any real platform or model, posting anything, accounts and sign-in, deployment, sending notifications.
