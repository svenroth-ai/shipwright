# Visual guidelines

Calm, high contrast, one accent colour. The board is the whole page: a tab strip and a list of cards, nothing else. Look and structure come from the Untitled UI design kit; this file supplies only the brand tokens, declared as `--name: value` lines so the kit can read them.
